# Thor-Roofing-Company
Thor Roofing Company is a Whop Website that runs the roofing deposit, job and final-invoice flow on Whop Payments. It has three real Whop plans: a $149 inspection, a $500 project deposit and a $189 flat-rate gutter clean. Checkout uses Whop Payment Elements (PaymentElement, EmailElement, the required BrandingElement and ExpressCheckoutElement for Apple Pay and Google Pay), so financing methods surface automatically for approved merchants. The deposit checkout saves the customer's card with a Setup Intent, charges the deposit to it, and the final balance is billed with the Invoices API by auto-charging the stored card or emailing an invoice for manual payment. The "Request an Estimate" form creates a Lead through the Leads API. The site fires custom pixel events through whop.track (estimate_requested, service_viewed, deposit_started) on top of Whop's automatic page-view and checkout tracking. All business details sit in one config file, so swapping company, services and pricing needs no structural changes.
